# 🏡 Kasa — Plateforme de location d’appartements (Frontend)

## 🎯 Ma mission

Développer le frontend complet de la nouvelle plateforme **Kasa**, un site de location d’appartements entre particuliers, en **React**.

---

## 🧰 Technologies utilisées

### 🔹 Framework / Librairies

* **React** (Create React App)
* **React Router**

### 🔹 Style

* **CSS** 
* **Sass / SCSS**

### 🔹 Outils

* **Figma** 
* **Git / GitHub** 

---

## 💡 Le projet

Kasa est un acteur majeur de la location entre particuliers en France.
Avec plus de **500 annonces postées chaque jour**, l’entreprise souhaite moderniser sa plateforme en développant une application web performante, responsive et maintenable.

---

## 📄 Fonctionnalités principales

### 🏠 Page d’accueil

* Liste toutes les annonces sous forme de cartes cliquables.
* Redirection vers la page de détails du logement.

### 📄 Page logement

* Affichage dynamique des détails : titre, hôte, note, description, équipements, etc.
* Galerie d’images avec **carousel**.
* Données chargées dynamiquement via **React Router**.

### ℹ️ Page À propos

* Présente Kasa et son fonctionnement à travers des **accordéons**.

### 🚫 Page 404

* Affichée pour toute route non définie.

---

## ⚙️ Cahier des charges technique

* Initialisation du projet avec **Create React App**
* Navigation avec **React Router**
* **Aucune librairie React externe** autorisée (hors React Router)
* Composants **réutilisables et modulaires**
* Application **responsive** (mobile → desktop)
* Respect de l’**accessibilité** (balises ARIA, focus visible)
* Code clair, commenté et conforme à la maquette Figma

---

## ⚙️ Installation du projet

### 1️⃣ Cloner le dépôt

```bash
git clone https://github.com/Eliaslvr/kasa.git
```

### 2️⃣ Installer les dépendances

```bash
cd kasa
npm install
```

### 3️⃣ Lancer le serveur de développement

```bash
npm start
```

L’application sera accessible sur **[http://localhost:3000](http://localhost:3000)**
